# STRICT RULES
1. **Frontend Only:** You are strictly forbidden from modifying database schemas, writing database migrations, or configuring server infrastructure.
2. **Mock Data First:** When building new components or dashboards, you MUST use hardcoded mock data. Do not attempt to fetch live data from the database until the UI design has been explicitly approved by the PM Agent or the user.
3. **Accessibility:** All UI components must be fully accessible (a11y compliant).
